## 二、发现的问题

### 🔴 问题1：消息投递队列有8条失败消息
- **位置：** ~/.openclaw/delivery-queue/failed/
- **原因：** 发送到 "security-reports" 渠道失败（400错误）
- **影响：** security-brand-analyst 的报告无法送达
- **建议：** 清理失败队列，检查 security-reports 渠道配置

### 🟡 问题2：3个子Agent仍有BOOTSTRAP.md
- **涉及：** xiaozhuge、xingqiliu、zhuli2hao
- **影响：** 每次唤醒可能重复执行引导流程
- **建议：** 确认初始化完成后删除 BOOTSTRAP.md

### 🟡 问题3：security-* 系列Agent未完全配置
- **涉及：** security-brand-analyst、security-copywriter、security-market-monitor
- **影响：** 这3个Agent不在 main 的 allowAgents 列表中，无法被主Agent调用
- **建议：** 如需使用，添加到 allowAgents；如不需要，清理

### 🟢 问题4：Gateway 服务未以 systemd 运行
- **当前：** 本地运行模式
- **影响：** 重启机器后需手动启动
- **建议：** 暂不处理，当前运行稳定

## 三、优化建议（按优先级）
