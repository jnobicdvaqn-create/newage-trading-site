## 一、定义和症状（2:20）

### 1. 什么是阿尔茨海默症？

- **阿尔茨海默症（AD）** 是老年人痴呆最常见的原因
- 一种慢性脑部疾病，逐渐破坏患者的**记忆和思考能力**
- 最终导致患者无法完成简单的日常任务
- 大多数症状在**65岁以后**才开始出现
- 目前是美国第六大死因（在老年人群中可能排第三，仅次于心脏病和癌症）

### 2. 痴呆 vs 阿尔茨海默

- **痴呆（Dementia）** 是一个总称，指认知功能和行为能力的丧失
- 阿尔茨海默症是痴呆的一种，也是最常见的一种
- 其他类型：路易体痴呆、额颞叶痴呆、血管性痴呆
- 不少患者有**混合性痴呆**（两种或以上痴呆同时存在）

### 3. 大脑病理变化

- **淀粉样蛋白斑块（Amyloid Plaques）**：大脑中的异常蛋白堆积
- **神经原纤维缠结（Tau Tangles）**：细胞内缠结的纤维束
- **神经元连接减少**：神经元之间传递信息的能力下降
- 这些变化可能在症状出现前 **10年甚至更早** 就已开始
- 损伤首先发生在**海马体（hippocampus）和内嗅皮层**——形成记忆的关键部位

### 4. 三个阶段的症状

#### 轻度阶段
- 记忆丧失逐渐加重
- 徘徊和迷路
- 难以处理金钱和账单
- 重复提问
- 完成日常任务耗时更长
- 性格与行为变化
- **通常在此阶段确诊**

#### 中度阶段
- 语言、推理、感官处理区域受损
- 认不出家人和朋友
- 无法学习新事物
- 无法完成多步骤任务（如穿衣）
- 可能出现**幻觉、错觉、偏执**
- 行为冲动

#### 严重阶段
- 蛋白斑块和纤维缠结遍布大脑
- 脑组织明显萎缩
- 无法与人沟通
- 完全依赖他人照顾
- 大部分时间卧床

### 5. 早期预警信号

- 记忆问题（最常见的早期信号）
- 行动困难
- 嗅觉问题
- 查找单词困难
- 视觉/空间问题
- 推理和判断能力受损
- **轻度认知障碍（MCI）** 是介于正常与痴呆之间的状态

## 二、病因和诊断（13:48）

### 1. 病因

#### 遗传因素
- **晚发性（>60岁）**：载脂蛋白E4（APOE ε4）基因增加风险，但不绝对
- **早发性（30-60岁）**：占总病例不到10%，可能由特定基因突变导致
- **唐氏综合症**患者风险很高（多一条21号染色体，含淀粉样蛋白基因）

#### 非遗传因素
- 心血管疾病（心脏病、中风、高血压）
- 糖尿病、肥胖症
- 大脑老化相关变化（萎缩、炎症、血管损害）
- 自由基和线粒体功能障碍

#### 保护因素
- 合理饮食营养
- 体育活动
- 社会交往
- 益智活动

### 2. 诊断方法

| 方法 | 具体内容 |
|------|---------|
| **病史询问** | 向患者及家属了解健康状况、用药、饮食、日常能力、行为变化 |
| **认知测试** | 记忆、解题、注意力、计数、语言测试 |
| **医学检查** | 验血、验尿，排除其他可能原因 |
| **脑部扫描** | CT、MRI、PET 等影像学检查 |
| **生物标记** | 脑脊液或血液中的疾病生物迹象（研究阶段） |

**重要提示：** 有记忆问题应尽早就医！可能的原因包括中风、肿瘤、帕金森、睡眠障碍、药物副作用等——**其中一些是可治疗的**。

## 三、治疗（29:35）

### 1. 症状管理药物（维持心理功能）

| 药物 | 适用阶段 | 作用机制 |
|------|---------|---------|
| **多奈哌齐（Donepezil）** | 轻度→重度 | 调节神经递质 |
| **利凡斯的明（Rivastigmine）** | 轻度→中度 | 调节神经递质 |
| **加兰他敏（Galantamine）** | 轻度→中度 | 调节神经递质 |
| **美金刚（Memantine）** | 中度→重度 | 调节神经递质 |

> ⚠️ 这些药物**无法改变疾病过程**，只能减轻症状，且对部分人有效，时间有限。

### 2. 疾病修饰治疗（DMT）

#### 已获批药物
- **阿杜卡努单抗（Aducanumab）**：首个获FDA批准的改善疗法，减少淀粉样蛋白沉积
- **仑卡奈单抗（Lecanemab）**：抗Aβ单克隆抗体，延缓认知衰退

#### 2026年中国最新进展
- ✅ 仑卡奈单抗已在中国获批
- ✅ 多地惠民保已纳入报销
- ✅ 实现"**有药可治、有钱长治**"

### 3. 行为症状管理
- 失眠、徘徊、焦虑、攻击性等
- 药物和非药物手段结合
- 治疗行为症状可显著提升患者和护理者的生活质量

### 4. 非药物干预
- 体育活动
- 合理饮食
- 认知训练
- 社会参与

## 四、护理（39:41）

### 1. 护理者面临的挑战

- **体力消耗**：日常照护需求大
- **情感压力**：角色变化、心理负担
- **经济负担**：治疗和护理费用
- **决策困难**：是否转入护理机构

### 2. 护理策略

| 策略 | 说明 |
|------|------|
| **了解疾病** | 学习各阶段知识，了解患者行为变化原因 |
| **应对技能** | 学习处理困难行为的方法 |
| **支持系统** | 寻找家人、朋友、社区的支持 |
| **暂息照顾** | 让护理者有机会休息恢复 |
| **互助小组** | 分享经验、获取建议、情绪支持 |
| **保持活动** | 护理者自身也需要身体和情感的健康 |

### 3. 给家属的建议

1. **尽早诊断**：早期治疗可帮助患者维持更长时间的日常功能
2. **提前规划**：处理财务、法律事务
3. **安全保障**：解决居家安全问题
4. **了解资源**：利用社区和医疗资源
5. **自我照顾**：护理者的健康同样重要

## 五、关键知识点总结

### ⭐ 核心要点

1. 阿尔茨海默症 ≠ 正常衰老，是一种疾病
2. 大脑变化在症状出现前**10+年**就已开始
3. **APOE ε4基因**增加风险但不是决定性的
4. 目前**没有治愈方法**，但有多种治疗手段
5. 仑卡奈单抗等新药带来了疾病修饰治疗的希望
6. **早期发现、早期干预**至关重要
7. 健康生活方式（运动、饮食、社交、益智活动）可降低风险
8. 护理者的身心健康同样需要关注

### 📊 风险因素 vs 保护因素

| 风险因素 | 保护因素 |
|---------|---------|
| APOE ε4 基因 | 规律运动 |
| 高血压 | 健康饮食（地中海饮食） |
| 糖尿病 | 社会交往 |
| 肥胖 | 益智活动 |
| 心血管疾病 | 良好睡眠 |
| 头部创伤 | 控制慢性病 |
| 缺乏运动 | 终身学习 |
