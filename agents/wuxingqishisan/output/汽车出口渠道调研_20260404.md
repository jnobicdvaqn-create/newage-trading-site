## 四、转口市场分析

### 4.1 格鲁吉亚汽车转口贸易概况

| 指标 | 数据 | 来源 |
|------|------|------|
| 2025年再出口量 | ~110,000辆 | 已确认事实 |
| 主要转口目的地 | 阿塞拜疆、亚美尼亚、中亚五国 | 行业共识 |
| 格鲁吉亚角色 | 高加索地区汽车贸易枢纽 | 已确认事实 |

### 4.2 转口目的地分析

#### 阿塞拜疆 🇦🇿
| 项目 | 详情 |
|------|------|
| **需求特点** | 石油经济，购买力较强，偏好SUV和豪华车 |
| **关税政策** | 根据车龄和排量征收关税，新车相对优惠 |
| **中国车现状** | BYD、奇瑞已有一定市场份额 |
| **贸易路线** | 第比利斯 → 巴库，陆运约6-8小时 |

#### 亚美尼亚 🇦🇲
| 项目 | 详情 |
|------|------|
| **需求特点** | 经济较弱，偏好经济型车和二手车 |
| **EAEU成员** | 欧亚经济联盟成员，关税与俄罗斯统一 |
| **中国车机遇** | 通过亚美尼亚可间接进入EAEU市场 |
| **贸易路线** | 第比利斯 → 埃里温，陆运约4小时 |

#### 中亚市场 🇰🇿🇺🇿🇰🇬🇹🇯🇹🇲
| 项目 | 详情 |
|------|------|
| **哈萨克斯坦** | 最大市场，EAEU成员，奇瑞/吉利已设工厂 |
| **乌兹别克斯坦** | 快速增长市场，Chevrolet占主导但中国车份额上升 |
| **吉尔吉斯斯坦** | 转口中心，对中国车接受度高 |
| **格鲁吉亚优势** | 零关税进口 → 转口高加索/中亚，避开直接出口的高关税 |

### 4.3 转口贸易链路

```
中国工厂/贸易商
    ↓ (海运至波季港/巴统港，约20-30天)
格鲁吉亚（波季港/巴统港）
    ↓ (清关，零/低关税)
格鲁吉亚自贸区/汽车市场
    ├→ 本地销售（~40%）
    ├→ 阿塞拜疆（陆运，6-8h）
    ├→ 亚美尼亚（陆运，4h）
    └→ 中亚（经里海/铁路）
```

### 4.4 关键港口与物流

| 港口 | 位置 | 功能 |
|------|------|------|
| **波季港（Poti）** | 格鲁吉亚西部 | 主要汽车进口港，有RORO码头 |
| **巴统港（Batumi）** | 格鲁吉亚西南 | 第二大港，靠近土耳其边境 |
| **阿纳克利亚深水港** | 规划中 | 未来可能成为中亚贸易枢纽 |
