## 三、需要主人手动操作的事项

### 🔴 P0（必须做）

#### 1. 设置GitHub分支保护规则

1. 访问: https://github.com/jnobicdvaqn-create/newage-trading-site/settings/branches
2. 点击 "Add rule"
3. Branch name pattern: `main`
4. 勾选以下选项：
   - ✅ **Require a pull request before merging**
   - ✅ **Require status checks to pass before merging**
   - ✅ **Require signed commits**（可选，增加安全性）
   - ✅ **Do not allow bypassing the above settings**（关键！防止管理员绕过）
   - ✅ **Restrict who can push to matching branches** → 只允许主人账号
5. 保存

#### 2. 开启GitHub双因素认证(2FA)

1. 访问: https://github.com/settings/security
2. 点击 "Enable two-factor authentication"
3. 选择方式：Authenticator app（推荐）或 SMS
4. 保存恢复码（重要！丢失后无法恢复账号）

#### 3. VPS上配置Nginx安全头

通过Spaceship Web Terminal连接VPS，执行：

```bash
sudo nano /etc/nginx/sites-available/newage-trading.conf

# 在 server { } 块中添加：
add_header X-Frame-Options 'SAMEORIGIN' always;
add_header X-Content-Type-Options 'nosniff' always;
add_header X-XSS-Protection '1; mode=block' always;
add_header Referrer-Policy 'strict-origin-when-cross-origin' always;
add_header Content-Security-Policy "default-src 'self' https:; script-src 'self' 'unsafe-inline' https://fonts.googleapis.com; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: https:; always;"
server_tokens off;

# 测试并重载
sudo nginx -t && sudo systemctl reload nginx
```

### 🟡 P1（建议做）

#### 4. 轮换GitHub Token

1. 访问: https://github.com/settings/tokens
2. 删除旧Token（见 `.git-credentials` 中当前Token）
3. 生成新Token（scope: repo）
4. 更新本地凭证：
   ```bash
   echo 'https://xw3046:NEW_TOKEN@github.com' > ~/.git-credentials
   ```

#### 5. 确认VPS fail2ban运行状态

通过Web Terminal：
```bash
systemctl status fail2ban
sudo fail2ban-client status
sudo fail2ban-client status sshd
```

#### 6. 开启域名自动续期

访问 Spaceship 控制面板，开启 Auto-Renew。
