## 一、修改流程总览

```
修改文件 → 本地构建 → Git提交 → 推送 → VPS自动部署（5分钟内生效）
```

### 快速命令

```bash
cd ~/openclaw/workspace

# 1. 修改文件（编辑任意 .astro / .json / .css 文件）

# 2. 构建验证
npx astro build

# 3. 提交并推送
git add -A
git commit -m "修改说明"
git push origin master:main

# 4. 等待VPS同步（约5分钟），然后浏览器查看
```

## 二、常见修改场景

### 场景1：修改汽车价格

**文件：** `src/data/cars.json`

```json
{
  "id": "byd-han",
  "brand": "BYD",
  "model": "Han EV",
  "price": "¥319,800",           ← 修改这里
  "priceRange": "$32,000-38,000", ← 修改这里
  ...
}
```

**步骤：**
1. 打开 `src/data/cars.json`
2. 找到对应车辆（按 `id` 搜索）
3. 修改 `price`（人民币价格）和 `priceRange`（美元区间）
4. 保存文件
5. 构建：`npx astro build`
6. 提交推送：`git add src/data/cars.json && git commit -m "update: BYD Han price" && git push origin master:main`

## 四、Git操作指南

### 基本操作

```bash
# 查看修改了哪些文件
git status

# 查看具体修改内容
git diff

# 提交修改
git add -A                    # 添加所有修改
git commit -m "修改说明"      # 提交

# 推送到远程
git push origin master:main

# 查看推送历史
git log --oneline -10
```

### 常见问题

**Q: push被拒绝怎么办？**
```bash
# 先拉取远程变更
git pull origin main --rebase
# 解决冲突（如果有）
# 再推送
git push origin master:main
```

**Q: 想撤销最后一次commit？**
```bash
git reset --soft HEAD~1    # 撤销commit，保留修改
git reset --hard HEAD~1    # 撤销commit，丢弃修改（危险！）
```

## 六、回滚到历史版本

如果改坏了，可以快速恢复：

```bash
# 方法1：使用备份脚本（推荐）
./tools/backup-restore.sh list               # 查看备份
./tools/backup-restore.sh restore 20260514_180000   # 恢复

# 方法2：Git回滚
git log --oneline -10                        # 查看历史
git reset --hard abc1234                     # 回退到指定commit
npx astro build                              # 重新构建
git push origin master:main --force          # 强制推送（谨慎！）
```

## 七、最佳实践

1. **修改前必备份**：每次大改前先 `./tools/backup-restore.sh backup`
2. **小步提交**：每次修改一个功能，单独commit
3. **构建后验证**：`npx astro build` 成功后再推送
4. **浏览器硬刷新**：VPS部署后用 `Ctrl+Shift+R` 强制刷新
5. **修改翻译三语同步**：改en时别忘了zh和ru
6. **图片换名必加版本号**：`?v=20260514d`
7. **推送前检查**：`git diff --cached --name-only` 看看要推什么
