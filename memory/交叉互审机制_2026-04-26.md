## 审核流程

1. **产出提交** → 被审核方完成任务后提交输出
2. **交叉审核** → 审核方在30分钟内完成审核
3. **审核意见** → 标注：✅通过 / ⚠️修改 / ❌重做
4. **修改确认** → 被审核方修改后再次提交
5. **归档记录** → 审核记录写入本文档

## 审核检查单

### 小诸葛审核星期六（风控/督促）
- [ ] 风险识别是否全面（≥3个风险点）
- [ ] 风险等级判定是否合理（高/中/低）
- [ ] 应对措施是否可操作
- [ ] 督促时间节点是否明确
- [ ] 是否标注逾期任务

### 星期六审核小诸葛（分析/质控）
- [ ] 数据来源是否标注（≥2个来源）
- [ ] 分析逻辑是否清晰
- [ ] 结论是否有数据支撑
- [ ] 建议是否具体可执行
- [ ] 是否标注不确定性
