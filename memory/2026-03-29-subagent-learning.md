## 📚 SubAgent 核心概念

### 什么是 SubAgent？
**子代理系统** - 允许主 Agent 创建和管理多个子代理并行执行任务

**特点：**
- 🔄 并行执行
- 🎯 任务分解
- 🤝 协作完成
- 📊 结果汇总

---

### 架构示例
```
主 Agent (Main)
├── SubAgent 1 (研究)
├── SubAgent 2 (分析)
├── SubAgent 3 (写作)
└── SubAgent 4 (审核)
```

---

### 使用场景

**1. 研究报告生成**
- 研究员 1：竞品信息
- 研究员 2：价格信息
- 研究员 3：渠道信息
- 分析师：整合分析
- 文案师：撰写报告

**2. 多语言内容制作**
- 文案师：中文原稿
- 翻译 1-3：多语言翻译
- 审核员：校对

**3. 四人小组夜间研讨**
- 星期五三世：信息收集
- 小诸葛：分析质控
- 星期六：风险评估
- 助理二号：审核执行

---

### SubAgent vs 独立 Agent

| 特性 | SubAgent | 独立 Agent |
|------|----------|------------|
| 创建方式 | 动态创建 | `openclaw agents add` |
| 生命周期 | 任务结束销毁 | 持久运行 |
| 资源占用 | 轻量级 | 独立进程 |
| 适用场景 | 临时任务 | 长期任务 |
