## 教程内容

### 1. 视频演示文件下载

**下载地址：**
https://github.com/qichiyuhub/rule/blob/main/config/mihomo/proxychain.yaml

### 2. singbox一键安装

**安装命令：**
```bash
bash <(curl -sL "https://raw.githubusercontent.com/qichiyuhub/autoshell/refs/heads/main/install_singbox.sh")
```

### 3. 启动服务

**启用服务：**
```bash
sudo systemctl enable sing-box
```

**启动singbox：**
```bash
sudo systemctl start sing-box
```

## 技术说明

链式代理是一种代理链路配置方式，可以实现：
- 多层代理转发
- 流量跳板加密
- IP地址隐藏增强
