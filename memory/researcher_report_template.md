# 研究员报告标准格式模板

**更新时间：** 2026-04-18 06:29
**来源：** 主人指示

---

## 标准格式要素

### 1. 标题结构
```
研究员X [主题]信息摘要（YYYY年M月D日）
```

### 2. 分隔线
使用 `───` 作为章节分隔

### 3. 数据表格化
宏观经济、政策数据用表格呈现：
```
| 指标 | 时间 | 数值 | 解读 |
|------|------|------|------|
```

### 4. 分类章节
- 📊 数据类 → 宏观经济数据
- 🔥 事件类 → 市场重大事件
- 🌍 国际类 → 国际地缘政治
- 🏠 国内类 → 国内政策与市场
- 📎 来源类 → 来源链接

### 5. 内容要点化
使用 bullet points（•）而非段落叙述

### 6. 风险提示
结尾必须包含风险提示/总结

### 7. 元信息
```
整理完成时间： YYYY-MM-DD HH:MM (Asia/Shanghai)
字数统计： 约 XXX 字
```

---

## 示例模板

```
研究员X [主题]信息摘要（YYYY年M月D日）

───

📊 [数据章节标题]

| 指标 | 时间 | 数值 | 解读 |
|------|------|------|------|
| XXX | XXX | XXX | XXX |

───

🔥 [事件章节标题]

• 要点1
• 要点2
• 要点3

───

📎 来源链接

• 来源1：https://...
• 来源2：https://...

───

风险提示/总结： [简短总结要点]

整理完成时间： YYYY-MM-DD HH:MM (Asia/Shanghai)
字数统计： 约 XXX 字
```

## 适用场景

| 研究员类型 | 报告主题 |
|------------|---------|
| R01-R05 | 政经信息摘要 |
| R06-R10 | 行业/市场信息 |
| R11-R15 | 教育/政策信息 |
| R16-R20 | 技术/趋势信息 |
| R21-R30 | 定制主题 |

**备注：** 此格式为主人指定标准，所有研究员报告需遵循。
