## 二、四种参与度详细方案

### 方案A：低参与度（纯推广）

**Digital Studio角色：** 数字营销代理（收月费/项目费）

| 项目 | 内容 |
|------|------|
| **合作模式** | 我方品牌，对方做推广 |
| **付款方式** | 月费$1,000-3,000 或 项目制$5,000-10,000 |
| **我方责任** | 品牌定位+供应链+产品+客服 |
| **对方责任** | 社媒运营+广告投放+内容创作 |
| **启动资金** | $15K-25K（库存+推广费）|
| **适合** | 我方有品牌控制权需求 |

**供应链方案：**
- 阶段1：中国进口（验证市场）
- 阶段2：本土CMT（灵活补货）
- 阶段3：混合模式（规模化）

**风险：** 推广效果不确定，可能白花钱

---

### 方案B：中参与度（设计+推广）

**Digital Studio角色：** 设计方+营销方

| 项目 | 内容 |
|------|------|
| **合作模式** | 对方设计+推广，我方生产 |
| **付款方式** | 设计费$3,000-8,000 + 推广费$1,000-2,000/月 |
| **我方责任** | 供应链+生产+品控+物流 |
| **对方责任** | 品牌设计+包装设计+营销推广 |
| **启动资金** | $10K-20K |
| **适合** | 我方有供应链优势，缺设计能力 |

**供应链方案：**
- 中国面料进口 + 格鲁吉亚本土CMT
- 成本低（$4.30/件），交付快（15-21天）

**风险：** 设计不符市场需求，库存积压

---

### 方案C：高参与度（品牌合资）

**Digital Studio角色：** 品牌共同所有者

| 项目 | 内容 |
|------|------|
| **合作模式** | 合资公司（如50/50或60/40）|
| **资金分摊** | 我方$20K-30K，对方$10K-20K |
| **我方责任** | 供应链+生产管理 |
| **对方责任** | 品牌+设计+本地营销+销售 |
| **启动资金** | $30K-50K（合计）|
| **适合** | 双方优势互补，深度绑定 |

**供应链方案：**
- 混合模式（中国核心部件+本土组装）
- 成本最优（$4.00-4.50/件）

**风险：** 利益分配纠纷，退出困难

---

### 方案D：全链路参与

**Digital Studio角色：** 全链路合作伙伴

| 项目 | 内容 |
|------|------|
| **合作模式** | 我方B2B供货，对方全权运营 |
| **付款方式** | 按件结算（如$5-8/件）|
| **我方责任** | 按订单供货 |
| **对方责任** | 品牌+设计+生产+营销+销售 |
| **启动资金** | $5K-10K（首批备货）|
| **适合** | 我方想轻资产运营 |

**供应链方案：**
- 纯中国生产→出口格鲁吉亚
- 或本土生产→直接供货

**风险：** 利润薄，依赖对方销量

## 三、摸底问题清单（视频会议用）

### 必问问题

| 序号 | 问题 | 目的 |
|------|------|------|
| 1 | "你们对内衣品牌项目有什么期待？" | 了解合作意图 |
| 2 | "你们能提供哪些服务？设计？营销？销售？" | 明确能力范围 |
| 3 | "你们希望以什么形式合作？服务费？合资？分成？" | 确定合作模式 |
| 4 | "你们在格鲁吉亚市场有什么资源？" | 评估本地优势 |
| 5 | "过往有类似品牌合作项目吗？" | 验证经验 |
| 6 | "你们的收费模式是什么？" | 预算规划 |
| 7 | "如果合作，你们建议的品牌定位是什么？" | 了解市场洞察 |
| 8 | "你们能承担多少前期投入？" | 判断资金实力 |

## 五、风险对冲策略

| 风险 | 对冲方案 |
|------|---------|
| 合作谈崩 | 保留方案A（自己做品牌）|
| 对方能力不足 | 降低合作深度，回到方案A |
| 资金不足 | 从方案D开始（轻资产）|
| 市场不买单 | 30天测试，止损清仓 |
