## 二、可观测性核心概念

### 2.1 什么是可观测性

**可观测性三支柱：**

| 支柱 | 说明 | 工具 |
|------|------|------|
| **日志（Logs）** | 事件记录 | OpenClaw日志文件 |
| **指标（Metrics）** | 数值监控 | Gateway状态 |
| **追踪（Traces）** | 调用链追踪 | Agent调用链 |

---

### 2.2 可观测性架构

**架构层级：**

```
应用层（Agent执行） → Gateway层（消息路由） → 系统层（进程监控）
```

**监控对象：**

| 层级 | 监控内容 |
|------|---------|
| **应用层** | Agent响应时间、任务完成率 |
| **Gateway层** | WebSocket连接状态、消息吞吐量 |
| **系统层** | 进程数、内存占用、端口状态 |

---

## 五、故障排查方法

### 5.1 Gateway双进程问题排查

**问题现象：**
- WebSocket连接不稳定
- 端口冲突

**排查步骤：**

| 步骤 | 命令 | 结果 |
|------|------|------|
| **1. 查进程** | `ps aux | grep gateway` | 发现2个进程 |
| **2. 查端口** | `lsof -i:18789` | 端口被占用 |
| **3. 杀旧进程** | `kill [旧PID]` | 只保留新进程 |
| **4. 重启Gateway** | `openclaw gateway restart` | 服务恢复正常 |

## 七、监控工具配置

### 7.1 OpenClaw Gateway监控

**监控脚本示例：**

```python
import subprocess
import time

def monitor_gateway():
    while True:
        # 查Gateway进程数
        result = subprocess.run(['ps', 'aux'], capture_output=True)
        gateway_count = len([l for l in result.stdout.decode().split('\n') if 'gateway' in l])
        
        if gateway_count > 1:
            print(f"⚠️ Gateway进程数异常: {gateway_count}")
        
        time.sleep(300)  # 每5分钟检查
```
