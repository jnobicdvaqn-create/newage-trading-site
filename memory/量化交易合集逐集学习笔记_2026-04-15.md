## EP01：量化交易基础概念

**学习内容：**

### 1.1 什么是量化交易

**定义：**
- 量化交易 = 用数学模型 + 计算机程序进行投资决策
- 特点：客观、可复制、纪律性强

**与传统交易对比：**

| 维度 | 传统交易 | 量化交易 |
|------|---------|---------|
| 决策方式 | 主观判断 | 数学模型 |
| 执行效率 | 手动/慢 | 程序化/快 |
| 纪律性 | 受情绪影响 | 严格执行 |
| 可验证性 | 难验证 | 回测验证 |

### 1.2 量化交易的核心要素

| 要素 | 说明 |
|------|------|
| **数据** | 历史价格、成交量、财务数据 |
| **模型** | 数学公式、统计方法 |
| **策略** | 买入/卖出规则 |
| **回测** | 用历史数据验证策略 |
| **风控** | 资金管理、止损机制 |

### 1.3 量化交易流程

```
数据获取 → 策略设计 → 回测验证 → 部署执行 → 监控优化
```

    # 处理缺失值

### 5.2 回测核心逻辑

```python
# 回测框架核心
def backtest_strategy(data, strategy, initial_capital):
    capital = initial_capital
    position = 0
    
    for i in range(len(data)):
        signal = strategy(data.iloc[i])
        
        if signal == 'buy' and position == 0:
            position = capital / data.iloc[i]['close']
            capital = 0
        
        elif signal == 'sell' and position > 0:
            capital = position * data.iloc[i]['close']
            position = 0
    
    final_value = capital + position * data.iloc[-1]['close']
    return final_value
```
