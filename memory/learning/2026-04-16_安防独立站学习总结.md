## 💡 学习心得

1. **Next.js + Tailwind CSS 是高效建站组合**
   - 开发速度快，10 分钟可完成基础原型
   - 响应式设计内置支持
   - SEO 友好（SSR/SSG）

2. **视频背景 + 渐变文字 = 高端感**
   - 视觉冲击力强
   - 提升品牌质感
   - 适合安防/汽车/内衣业务线

3. **Vercel 部署零成本**
   - 免费计划足够初期使用
   - 自动 CI/CD
   - 全球 CDN 加速

4. **可复用性强**
   - 同一套模板可用于三条业务线
   - 只需更换内容和颜色主题
   - 维护成本低
