## 🎯 核心优化方向

### 双均线优化（优先级排序）

| 方法 | 效果 | 代码要点 |
|------|------|---------|
| **MACD过滤** | 胜率+5-10% | `short_ma > long_ma AND macd_hist > 0` |
| **ATR仓位** | 风险可控 | `units = risk_amount / (atr * 2)` |
| **移动止损** | 保护利润 | `stop = max_price * 0.97`（盈利3%后启用） |
| **RSI过滤** | 避追高杀低 | `long: RSI < 70, short: RSI > 30` |
| **成交量确认** | 信号质量+ | `volume_ratio > 1.5` |

## 🛡️ 风控铁律

### 仓位管理

```
单笔风险 ≤ 2%总资金
单品种仓位 ≤ 30%
总仓位 ≤ 70%
```

### 止损组合

```
固定止损：5%（保底）
移动止损：3%回撤（盈利后）
时间止损：20天（强制平仓）
```

### 熔断阈值

```
日亏损 ≥ 3% → 暂停
周亏损 ≥ 5% → 暂停
月亏损 ≥ 10% → 暂停
```

## 📊 回测检验标准

| 检验项 | 通过标准 |
|--------|---------|
| 样本外衰减 | ≤ 30% |
| 滚动窗口夏普 | ≥ 0.8 |
| 参数稳定性 | 标准差 ≤ 0.3 |
| 成本敏感性 | 0.2%成本下仍盈利 |

## 🚀 实盘过渡三阶段

### 阶段1（1-2月）：5-10%资金验证

- 单笔≤10%，总仓位≤30%
- 目标：月收益>0，回撤<10%

### 阶段2（2-3月）：20-30%资金运行

- 单笔≤20%，总仓位≤50%
- 目标：连续盈利2月，夏普>0.8

### 阶段3：50-70%资金正常运行

- 单笔≤25%，总仓位≤70%
- 目标：稳定盈利，持续优化

## ⚠️ 策略失效信号

| 指标 | 预警阈值 | 处理 |
|------|---------|------|
| 连续亏损 | 20天中15天亏 | 暂停复盘 |
| 夏普下降 | < 历史50% | 检查参数 |
| 胜率下降 | < 历史70% | 调整策略 |
| 最大回撤 | > 15% | 暂停交易 |
