## 💡 升级建议

### 建议1：建立客户评分模型

```
评分维度：
- 公司规模（大/中/小）: 0-30分
- 进口能力（有/无）: 0-20分
- 相关品类经验（有/无）: 0-20分
- 回复积极性（高/中/低）: 0-15分
- 预算匹配度（高/中/低）: 0-15分

总分 ≥ 70 → P0优先跟进
总分 50-69 → P1正常跟进
总分 < 50 → P2保持联系
```

### 建议2：建立话术库

| 场景 | 话术模板 | 适用业务 |
|------|---------|---------|
| 首次开发 | 公司介绍+价值主张 | 汽车/内衣/安防 |
| 跟进邮件 | 问题+行动呼吁 | 所有业务 |
| 价格谈判 | 锚定+长期合作 | 内衣OEM |
|  WhatsApp跟进 | 轻松打招呼+具体问题 | 汽车出口 |

### 建议3：建立转化漏斗跟踪

```
发送量(100%) → 打开量(40%) → 回复量(10%) → 意向量(3%) → 成交(1%)
     ↓              ↓              ↓              ↓            ↓
   100封          40封           10封           3封         1单
```
