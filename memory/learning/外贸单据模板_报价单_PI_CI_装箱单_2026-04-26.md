## 一、第1页：外贸报价单（QUOTATION）

**抬头信息区：**
| 字段 | 说明 |
|------|------|
| **Company Name** | 公司名称（卖方） |
| **Add / Tel / Email** | 地址/电话/邮箱 |
| **QUOTATION** | 报价单标题 |
| **To** | 买方名称 |
| **Attn** | 联系人 |
| **Tel** | 买方电话 |
| **Date** | 日期 |
| **Quote No.** | 报价单编号 |
| **Payment Terms** | 付款条款 |
| **Delivery Time** | 交货期 |

**报价表格区：**
| 列名 | 说明 |
|------|------|
| **Item** | 序号 |
| **Description** | 产品描述 |
| **Specification** | 规格参数 |
| **Unit** | 单位 |
| **Qty** | 数量 |
| **Unit Price (USD)** | 单价（美元） |
| **Amount (USD)** | 金额（美元） |

**底部信息区：**
- 总金额（Total Amount）
- 备注（Remarks）
- 签字盖章区
- 公司名称/日期

**用途：** 给客户报价，留谈判空间，价格不说死

## 五、4种单据的用途对比

| 单据 | 英文 | 用途 | 阶段 |
|------|------|------|------|
| **报价单** | Quotation | 给客户报价，留谈判空间 | 谈判阶段 |
| **形式发票** | Proforma Invoice | 客户申请进口许可/外汇 | 成交阶段 |
| **商业发票** | Commercial Invoice | 海关清关、银行结汇 | 发货阶段 |
| **装箱单** | Packing List | 海关查验、物流配载 | 发货阶段 |

### 使用流程

```
报价单(谈判) → 形式发票(成交) → 商业发票+装箱单(发货)
```
