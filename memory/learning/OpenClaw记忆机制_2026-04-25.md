## 视频1：探索OpenClaw龙虾的记忆机制（15分钟）

### 一、OpenClaw记忆的四个层级

| 层级 | 类比 | 说明 |
|------|------|------|
| **模型底层记忆** | 训练数据 | 模型预训练阶段学到的知识 |
| **短期记忆** | 电脑内存RAM | 当前会话的上下文窗口 |
| **长期记忆** | 电脑硬盘 | OpenClaw构建的持久化记忆 |
| **外挂记忆** | 外接存储 | LanceDB等向量数据库 |

### 二、记忆通路检查

1. 打开OpenClaw配置管理器 → 记忆管理页面
2. 点击"整段"检测
3. **全绿** = 记忆通路畅通
4. **有红色报错** = 记忆功能不完整

### 三、模型底层记忆

- 模型能力来源于训练数据
- 不同底座模型效果天差地别
- 后训练阶段的人类对齐影响回复风格
- 模型记忆稳定，参数一致则回复稳定
- 回复风格可用提示词缓解，但无法根治

### 四、短期记忆（上下文窗口）

- 只存在于当前会话
- 类比为电脑内存，关机后消失
- 不同模型的上下文窗口大小不同
- 影响当前对话能记住的内容量

### 五、长期记忆

- OpenClaw构建的持久化存储
- 跨会话保留
- 通过配置文件管理

### 六、免费模型福利（CodeBuff）

**获取方式：**
1. 安装`freebuff`工具（Mac/Linux/Windows PowerShell）
2. 需要Node.js环境
3. 用GitHub账号登录
4. 获取凭证文件路径：
   - Mac：`~/.config/freebuff/credentials`
   - Windows：`C:\Users\用户名\.config\freebuff\credentials`
5. 在OpenClaw配置中集成

**可用模型：**
- ✅ GOM5.1mmX（推荐）
- ❌ mmX2.7（已不可用）
- ❌ GOM3.1（已不可用）

**注意：** 可能会遇到限流排队，需等待后重试

## 视频2：龙虾可视化配置管理器（29分钟）

### 一、Provider（提供商）概念

| 概念 | 类比 | 说明 |
|------|------|------|
| **Provider** | 银行（工行/农行） | AI服务提供商 |
| **Base URL** | 银行地址 | API访问地址 |
| **API Key** | 银行卡密码 | 访问凭证 |
| **API类型** | 语言（中文/英文） | 通信协议类型 |

### 二、国内AI服务商

| 服务商 | Base URL示例 | 说明 |
|--------|-------------|------|
| Kimi | 官方文档提供 | Moonshot AI |
| DeepSeek | 官方文档提供 | 与OpenAI兼容 |
| 豆包 | 字节跳动 | 火山引擎 |
| 通义千问 | 阿里云 | 阿里旗下 |
| 讯飞星火 | 科大讯飞 | 讯飞旗下 |

### 三、API协议类型

| 协议 | 来源 | 说明 |
|------|------|------|
| **OpenAI Completion** | OpenAI | 较老协议 |
| **OpenAI Response** | OpenAI | 较新协议，用于Codex |
| **Gemini** | Google | 谷歌独有协议 |
| **Anthropic Messages** | Anthropic | Claude背后的公司 |

### 四、配置步骤

1. **添加Provider**
   - 名称（便于识别，如"DeepSeek"）
   - API Key
   - Base URL
   - API类型

2. **测试连通性**
   - 点击测试按钮
   - 确认连接成功

3. **获取模型列表**
   - 点击"获取模型"
   - 选择所需模型

4. **Agent模型配置**
   - 选择Agent
   - 选择Provider和模型
   - 保存（通常无需重启Gateway）

### 五、Skill管理

- 支持可视化配置Skill
- 可管理本地和远程龙虾
- 支持自动备份功能

### 六、远程SSH管理

- 支持SSH密钥登录
- 不支持密码输入
- 需要本地机器能免密登录远程机器
- 配置完成后，左侧功能访问的都是远程配置
