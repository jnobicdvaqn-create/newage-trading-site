## 🎯 GitHub 核心概念学习

### 1. 什么是 Git？
- **版本控制系统**：跟踪代码变更历史
- **分布式**：每个开发者都有完整代码库副本
- **分支管理**：支持多人协作开发

### 2. 什么是 GitHub？
- **代码托管平台**：基于 Git 的云端仓库
- **协作工具**：Pull Request、Issues、Actions
- **社交编程**：Star、Fork、Follow

### 3. 核心工作流

```
本地开发 → git add → git commit → git push → GitHub → Vercel 自动部署
```

| 步骤 | 命令 | 说明 |
|------|------|------|
| 初始化 | `git init` | 创建本地仓库 |
| 添加文件 | `git add .` | 暂存所有变更 |
| 提交 | `git commit -m "说明"` | 提交到本地仓库 |
| 关联远程 | `git remote add origin <URL>` | 连接 GitHub 仓库 |
| 推送 | `git push -u origin main` | 推送到 GitHub |

## 🔐 GitHub 认证方式

### 方式 1：Personal Access Token (PAT)
```bash
# 创建 Token 步骤：
# 1. GitHub → Settings → Developer settings → Personal access tokens
# 2. 生成新 Token（选择 repo 权限）
# 3. 复制 Token（只显示一次）
# 4. 使用 Token 代替密码

git remote add origin https://<TOKEN>@github.com/<用户名>/<仓库名>.git
git push -u origin main
```

### 方式 2：SSH Key
```bash
# 生成 SSH Key
ssh-keygen -t ed25519 -C "your_email@example.com"

# 查看公钥
cat ~/.ssh/id_ed25519.pub

# 添加到 GitHub：
# Settings → SSH and GPG keys → New SSH key
# 粘贴公钥内容

# 测试连接
ssh -T git@github.com

# 使用 SSH 推送
git remote add origin git@github.com:<用户名>/<仓库名>.git
git push -u origin main
```

## 🚀 Vercel 部署流程

### 1. 连接 GitHub 仓库
- 访问 [vercel.com](https://vercel.com)
- 使用 GitHub 账号登录
- Import Git Repository → 选择仓库

### 2. 自动部署配置
- Vercel 自动检测 Next.js 项目
- 配置构建命令：`npm run build`
- 配置输出目录：`.next`

### 3. 自定义域名（可选）
- 在 Vercel 项目中添加域名
- 配置 DNS 记录（CNAME/A）
- 自动 SSL 证书

### 4. 持续部署
- 每次 push 到 main 分支自动部署
- 生成预览链接（每个 PR）
- 全球 CDN 加速
