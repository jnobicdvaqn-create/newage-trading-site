## 一、四大核心单据概述

| 单据 | 英文全称 | 中文 | 用途 | 阶段 |
|------|---------|------|------|------|
| **Quotation** | Quotation Sheet | 报价单 | 向客户报价 | 询盘阶段 |
| **PI** | Proforma Invoice | 形式发票 | 确认订单，用于付款 | 成交阶段 |
| **CI** | Commercial Invoice | 商业发票 | 清关、结算 | 发货阶段 |
| **PL** | Packing List | 装箱单 | 清关、核对货物 | 发货阶段 |

## 二、报价单（Quotation Sheet）

### 2.1 作用
- 向潜在客户提供产品价格
- 建立初步商务关系
- 展示公司专业性

### 2.2 必备要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 公司信息 | 公司名、地址、联系方式 | XXX Co., Ltd. |
| 报价日期 | 报价有效期 | Valid until: 2026-05-25 |
| 产品描述 | 品名、规格、型号 | Women's Bra, Size S/M/L |
| 单价 | 含贸易术语 | USD 2.50/pc FOB Ningbo |
| MOQ | 最小起订量 | 500 pcs |
| 包装 | 包装方式 | 1pc/polybag, 50pcs/carton |
| 交货期 | 生产+运输时间 | 25-30 days after payment |
| 付款方式 | T/T, L/C等 | 30% deposit, 70% before shipment |
| 有效期 | 报价有效期限 | 30 days |

### 2.3 报价模板结构

```
┌─────────────────────────────────────┐
│          QUOTATION SHEET            │
│  Company: XXX Co., Ltd.             │
│  Date: 2026-04-25                   │
│  Valid Until: 2026-05-25            │
├─────────────────────────────────────┤
│ Item | Description | Qty | Unit Price│
│  1   | Product A   | 500  | $2.50/pc │
│  2   | Product B   | 300  | $3.80/pc │
├─────────────────────────────────────┤
│ Terms:                               │
│ - Payment: 30% T/T deposit           │
│ - Delivery: 25-30 days               │
│ - Packing: Standard export carton    │
│ - Validity: 30 days                  │
└─────────────────────────────────────┘
```

## 三、形式发票（PI - Proforma Invoice）

### 3.1 作用
- **确认订单**：买卖双方确认交易细节
- **付款依据**：客户凭PI去银行付款/开信用证
- **非正式发票**：不具备税务效力，但具有合同性质

### 3.2 必备要素

| 要素 | 说明 |
|------|------|
| PI编号 | 唯一识别码 |
| 日期 | 开具日期 |
| 买方信息 | 公司名、地址、联系人 |
| 卖方信息 | 公司名、地址、联系方式 |
| 产品明细 | 品名、规格、数量、单价、总价 |
| 贸易术语 | FOB/CIF/EXW等 |
| 付款方式 | T/T, L/C, Western Union等 |
| 装运信息 | 装运港、目的港、预计装运日期 |
| 银行信息 | 收款账户信息 |

### 3.3 PI vs 正式发票

| 对比 | PI（形式发票） | CI（商业发票） |
|------|---------------|---------------|
| 时间 | 成交时 | 发货时 |
| 效力 | 确认订单，非税务凭证 | 清关、结算凭证 |
| 用途 | 客户付款依据 | 海关申报、财务记账 |
| 金额 | 可与CI不同（预付款） | 实际交易金额 |

## 四、商业发票（CI - Commercial Invoice）

### 4.1 作用
- **清关必备**：海关核定关税的依据
- **结算凭证**：银行付款依据
- **税务凭证**：财务记账、退税依据

### 4.2 必备要素

| 要素 | 说明 |
|------|------|
| 发票编号 | 唯一识别码 |
| 日期 | 开具日期 |
| 买方/卖方 | 完整公司信息 |
| 产品明细 | 品名、规格、数量、单价、总价 |
| HS编码 | 海关编码 |
| 原产国 | Country of Origin |
| 贸易术语 | FOB/CIF/CFR等 |
| 总金额 | 含币种 |
| 签字盖章 | 公司公章+签字 |

### 4.3 注意事项
- 金额必须与实际交易一致
- HS编码必须准确（影响关税）
- 描述必须与报关单一致

## 五、装箱单（PL - Packing List）

### 5.1 作用
- **清关必备**：海关核对货物
- **收货核对**：买家清点货物
- **物流依据**：运输公司配载

### 5.2 必备要素

| 要素 | 说明 |
|------|------|
| 箱号 | Carton No. (1/N, 2/N...) |
| 产品名称 | Product Name |
| 规格型号 | Specification |
| 数量 | Quantity per carton |
| 毛重 | Gross Weight (G.W.) |
| 净重 | Net Weight (N.W.) |
| 体积 | Measurement (CBM) |
| 总箱数 | Total Cartons |
| 唛头 | Shipping Mark |

### 5.3 示例

```
┌──────────────────────────────────────────────┐
│            PACKING LIST                       │
├──────────────────────────────────────────────┤
│ Carton | Product    | Qty | G.W. | N.W. | CBM │
│   1-5  | Bra A      | 250 | 15kg | 12kg | 0.08│
│  6-10  | Bra B      | 200 | 14kg | 11kg | 0.07│
│ 11-15  | Panty C    | 300 | 10kg | 8kg  | 0.06│
├──────────────────────────────────────────────┤
│ Total: 15 cartons | G.W.: 195kg | N.W.: 155kg│
│ Total CBM: 1.05                                │
└──────────────────────────────────────────────┘
```

## 六、外贸单据全流程

```
客户询盘
  ↓
制作报价单（Quotation）
  ↓
客户确认 → 制作形式发票（PI）
  ↓
客户付款（凭PI）
  ↓
安排生产
  ↓
生产完成 → 制作商业发票（CI）+ 装箱单（PL）
  ↓
报关发货
  ↓
客户凭CI+PL清关
  ↓
交易完成
```

## 七、对我们的业务启示

### 7.1 当前业务线应用

| 业务线 | 需要哪些单据 | 优先级 |
|--------|------------|--------|
| 🚗 汽车出口 | 报价单 → PI → CI → PL | P0 |
| 👗 内衣OEM | 报价单 → PI → CI → PL | P0 |
| 🔒 安防装备 | 报价单 → PI → CI → PL | P0 |

### 7.2 立即行动

| 行动 | 说明 |
|------|------|
| 制作标准报价单模板 | 含汽车/内衣/安防三条线 |
| 制作PI模板 | 含银行信息、贸易术语 |
| 制作CI模板 | 含HS编码、原产国 |
| 制作PL模板 | 含箱号、重量、体积 |

### 7.3 注意事项

| 注意事项 | 说明 |
|---------|------|
| 报价单要注明有效期 | 避免原材料涨价风险 |
| PI要写清楚付款方式 | 避免付款纠纷 |
| CI金额必须准确 | 影响清关和退税 |
| PL必须与实际一致 | 海关查验会核对 |
