## 关键外贸知识

### 贸易术语
| 术语 | 全称 | 说明 |
|------|------|------|
| **FOB** | Free On Board | 离岸价，卖方负责到装船 |
| **CIF** | Cost, Insurance, Freight | 到岸价，含运费+保险 |
| **EXW** | Ex Works | 工厂交货，买方自提 |

### 付款方式
| 方式 | 说明 |
|------|------|
| **TT** | 电汇（Telegraphic Transfer） |
| **30% TT deposit** | 30%定金，70%发货前付清 |
| **L/C** | 信用证（Letter of Credit） |

### 单据流程
```
报价单(Quotation) → 形式发票(PI) → 客户付定金 → 生产 → 商业发票(CI)+装箱单 → 发货 → 客户付尾款
```
