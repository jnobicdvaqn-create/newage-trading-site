## 核心内容

### 功能
通过手机、Telegram、飞书等应用程序远程控制Agent

### 类比：快递物流
包裹在集散中心根据地址信息路由，直到送到收件人

### 核心组件
| 组件 | 功能 |
|------|------|
| **网关调度器** | 监听端口接收发送消息 |
| **WebSocket** | 监听信号 |
| **路由表** | 记录账号→Agent对应关系 |
| **会话管理** | 重构上下文 |

### 五层路由结构
1. **用户级** - 一一对应
2. **群组级** - 群发逻辑，一个Agent对接多客户端
3. **账户级** - 特定账号→Agent
4. **平台级** - Telegram/飞书专用Agent
5. **兜底级** - 默认Agent处理

### 路由流程
```
端口收到消息 → 解析地址 → 查路由表 → 找AgentID
  ↓ 找会话Key → 加载历史会话 → 重建上下文
  ↓ 开启独立运行环境 → Agent执行 → 返回消息 → 保存会话
```
