## 六、迁移SOP（草稿）

```bash
# 1. 停服务
openclaw gateway stop
cd ~/openclaw/workspace/ClawSwarm-repo/scheduler-server && pkill -f run_dev.py

# 2. 打包
tar -czf openclaw-backup-$(date +%Y%m%d).tar.gz ~/openclaw/ ~/.openclaw/

# 3. 传输（到目标机器）
scp openclaw-backup-*.tar.gz user@new-server:/path/to/

# 4. 恢复
# 4.1 准备Node.js环境
# 4.2 解压
tar -xzf openclaw-backup-*.tar.gz -C /home/user/
# 4.3 Fix权限
chown -R $USER:$USER ~/openclaw/ ~/.openclaw/
# 4.4 重启
openclaw gateway start
# 4.5 检查
openclaw status
```
