## 核心内容

### 问题
> "电脑死机、断网、丢包、网络不稳定的突发状况。"

### 解决方案

**消息队列管理：**
- 消息发送入队列 → 投递成功→删除 / 投递失败→失败队列→重试2-3次

**原子写入机制：**
- 先写临时文件 → 强制刷盘（fsync）→ 重命名为目标文件
- 确保断电时原文件不丢失、新消息完整

**守护进程：**
- 后台死循环运行，定时扫描消息队列
- 发送成功→删除 / 失败→放入失败队列→重试
