## 四、WhatsApp沟通技巧

### 1. 首次联系模板

```
您好！[对方姓名/公司名]

我是[姓名]，来自中国[公司名]。
我们专注于[产品类别]的生产和出口。

了解到贵司在[行业]领域很有影响力，
希望能与您建立联系，探讨合作机会。

如果您有兴趣了解我们的产品，
我可以发送产品目录和报价单。

期待您的回复！
[姓名]
[公司名]
[网址]
```

### 2. 注意事项

| 要点 | 说明 |
|------|------|
| **时间选择** | 考虑时差，工作时间发送 |
| **语言** | 英文为主，可准备当地语言版本 |
| **简洁** | WhatsApp不适合长消息 |
| **专业** | 使用商务头像和状态 |
| **跟进** | 2-3天未回复可跟进一次 |

### 3. 避免被拉黑

| 避免 | 建议 |
|------|------|
| 群发消息 | 一对一个性化沟通 |
| 频繁发送 | 控制频率，2-3天一次 |
| 长篇大论 | 简洁明了 |
| 直接报价 | 先了解需求 |
| 没有称呼 | 使用对方姓名/公司名 |
