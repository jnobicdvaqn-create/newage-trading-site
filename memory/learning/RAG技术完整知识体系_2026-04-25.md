## 一、RAG技术原理

### 1.1 核心概念
**RAG = Retrieval-Augmented Generation（检索增强生成）**

> 将外部知识库与大语言模型结合，通过检索相关信息来增强模型的生成能力。

### 1.2 工作流程

```
离线阶段：
多源数据(PDF/Word/HTML) → 清洗分块 → 向量转换 → 存储到向量数据库

在线阶段：
用户查询 → 向量检索 → 相关文本块 → 结合查询生成回答
```

| 阶段 | 步骤 | 说明 |
|------|------|------|
| **离线** | 1. 数据收集 | PDF、Word、HTML等多源数据 |
| | 2. 清洗分块 | 按语义边界分块，非固定字符数 |
| | 3. 向量转换 | 使用BERT/Sentence-BERT等嵌入模型 |
| | 4. 索引存储 | 存入向量数据库（Pinecone/Milvus） |
| **在线** | 1. 查询处理 | 向量化用户查询 |
| | 2. 检索匹配 | 相似度检索Top-K文本块 |
| | 3. 结合生成 | 检索结果+查询 → LLM生成回答 |

## 二、RAG技术架构

| 组件 | 功能 | 常用工具 |
|------|------|---------|
| **数据工程** | 收集、清洗、分块 | LangChain, Unstructured |
| **文档嵌入** | 文本→向量 | BERT, Sentence-BERT |
| **索引建立** | 向量存储+检索 | Pinecone, Milvus, FAISS |
| **检索处理** | 查询优化+排序 | BM25, Cross-BERT |
| **内容生成** | 检索+生成回答 | GPT, Claude, 本地LLM |
| **评估** | 性能评估 | BLEU, ROUGE, 人工标注 |

## 三、RAG优化策略

### 3.1 数据处理优化

| 策略 | 说明 |
|------|------|
| **智能分块** | 按语义边界（段落/章节）分块，非固定字符数 |
| **块大小实验** | 256/512/1024 tokens，用召回率评估 |
| **元数据保留** | 技术文档保留标题层级 |
| **Overlap避免割裂** | RecursiveCharacterTextSplitter + overlap |

### 3.2 检索策略优化

| 策略 | 说明 | 效果 |
|------|------|------|
| **HyDE** | LLM先生成"假设性答案"，再用它检索 | 提升语义匹配 |
| **多查询** | 一个用户问题→多个子问题→分别检索→汇总 | 提升召回率 |
| **混合搜索** | 向量检索(语义) + BM25(字面) | 召回率+准确率双提升 |
| **重排序** | 混合搜索召回 → Cross-Encoder重排 | Top-K相关性显著提升 |
| **多跳检索** | 检索→生成新查询→再检索 | 复杂问题逼近答案 |

### 3.3 向量数据库调优

| 优化 | 说明 |
|------|------|
| **HNSW索引** | 近似最近邻，适合高维向量，低延迟 |
| **相似度阈值** | cosine < 0.4的chunk直接丢弃 |
| **元数据过滤** | 按文档类型/时间/权限筛选，缩小范围 |
| **ef_search=128** | Pinecone/Milvus中提升召回精度 |

### 3.4 生成质量优化

| 策略 | 说明 |
|------|------|
| **上下文压缩** | LLM-based summarization剔除冗余 |
| **Token控制** | 限制在4K tokens内，避免超出窗口 |
| **高级提示工程** | CoT引导推理，提升逻辑性 |
| **LLM微调** | RAG特定微调（如RAFT）增强适应性 |

## 四、部署模式

| 模式 | 工具 | 适用场景 |
|------|------|---------|
| **云平台** | 阿里云PAI、腾讯云 | 快速验证、原型开发 |
| **本地私有** | n8n、AnythingLLM | 数据敏感、本地知识库 |
| **容器化** | Docker、Kubernetes | 生产环境、快速扩展 |

### 4.1 云平台部署要点

| 项目 | 建议 |
|------|------|
| LLM一体化部署 | 适合快速验证 |
| LLM分离式部署 | 适合生产环境，建议8核CPU+16GB内存 |

### 4.2 本地部署工具

| 工具 | 特点 |
|------|------|
| **n8n** | 低代码，拖拽构建工作流 |
| **AnythingLLM** | 支持多种大模型和向量数据库，上传多形式资料 |
