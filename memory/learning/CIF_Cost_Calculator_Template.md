# CIF报价成本计算模板

## 快速计算工具

### 模板结构

| 项目 | 公式 | 说明 |
|------|------|------|
| **A. FOB成本** | 采购价 + 国内杂费 + 利润 | 离岸价格基础 |
| **B. 海运费** | 单价 × 数量 | 目的港：波季/巴统 |
| **C. 保险费** | CIF × 1.1 × 0.5% | 投保加成110% |
| **D. CIF价格** | A + B + C | 最终报价 |

## 使用说明

1. **填写FOB成本：** 输入采购价、国内杂费和预期利润
2. **确认运费：** 向货代询价，获取最新海运费报价
3. **计算保险费：** 使用公式 CIF × 1.1 × 费率（0.5%-0.8%）
4. **得出CIF报价：** FOB + 运费 + 保险费
5. **买家成本估算：** CIF × 1.18 + 清关费（格鲁吉亚进口）
