# 📋 质控SOP - 审核标准清单

**制定时间：** 2026-04-22 14:17
**制定原因：** 民主生活会决议D-016 - 重建审核机制
**适用范围：** 所有对外输出（报告、邮件、推送、决策建议）

---

## 🔴 核心铁规

### 铁规一：三源验证（必执行）

**所有报告必须≥3个独立来源验证**

| 来源类型 | 示例 | 权重 |
|---------|------|------|
| **一手来源** | 官方文件、原始数据、当事人证言 | 高 |
| **权威媒体** | 官媒、行业权威媒体 | 中 |
| **交叉验证** | 多个独立信息源互相印证 | 高 |
| **专家意见** | 行业专家分析 | 低（需标注） |

**什么算"独立来源"？**

| 判断标准 | 说明 |
|---------|------|
| 独立采访 | 不同记者/机构独立报道 |
| 独立数据 | 不同数据源独立统计 |
| 独立分析 | 不同专家独立得出相同结论 |

**什么不算"独立来源"？**

| 情况 | 说明 |
|------|------|
| 转载/引用 | 同一报道被多家媒体转载 |
| 关联来源 | A引用B，B引用A |
| 单一信源 | 只有一个来源的多次表述 |

### 铁规二：真实性标注（必执行）

**推断内容必须标注"推断"**

| 内容类型 | 标注 | 示例 |
|---------|------|------|
| **事实** | 无标注 | "公司成立于2020年" |
| **推断** | 【推断】 | "【推断】市场预计增长10%" |
| **预测** | 【预测】 | "【预测】Q4销量可能达X" |
| **待验证** | 【待验证】 | "【待验证】传闻称..." |
| **引用** | 【引用】 | "【引用】XX媒体称..." |

**判断标准：**

| 情况 | 判定为 | 标注 |
|------|--------|------|
| 有官方文件/数据支撑 | 事实 | 无标注 |
| 有多个独立来源交叉验证 | 事实 | 无标注 |
| 基于事实的逻辑推导 | 推断 | 【推断】 |
| 基于趋势的外推预测 | 预测 | 【预测】 |
| 只有一个来源 | 待验证 | 【待验证】 |
| 直接引用他人观点 | 引用 | 【引用】 |

## 📋 质控审核清单

### 清单一：来源检查

- [ ] 是否有≥3个独立来源？
- [ ] 来源是否可信？（官方>权威媒体>普通媒体>自媒体）
- [ ] 来源是否有利益冲突？
- [ ] 是否区分了一手来源和转载来源？
- [ ] 是否标注了引用来源？

### 清单二：逻辑检查

- [ ] 推理链条是否完整？
- [ ] 是否存在逻辑跳跃？
- [ ] 是否有因果关系混淆？
- [ ] 是否有以偏概全？
- [ ] 是否有时间线错误？

### 清单三：事实验证

- [ ] 关键数据是否有官方来源？
- [ ] 关键日期是否有多个来源印证？
- [ ] 关键人物是否有公开信息验证？
- [ ] 关键事件是否有时间线验证？
- [ ] 是否有未标注的推断？

### 清单四：推断标注

- [ ] 所有推断是否标注【推断】？
- [ ] 所有预测是否标注【预测】？
- [ ] 所有待验证信息是否标注【待验证】？
- [ ] 所有引用是否标注【引用】？
- [ ] 推断是否说明依据？

## 🔍 三源验证SOP

### 步骤一：信息收集

1. **搜索关键词**：提取核心关键词
2. **多渠道搜索**：
   - 官方渠道：政府网站、官方公告
   - 权威媒体：新华社、人民日报、行业权威媒体
   - 国际渠道：国际组织、外媒（如适用）
3. **记录来源**：记录每个来源的URL、标题、发布时间

### 步骤二：来源评估

| 评估维度 | 高可信 | 中可信 | 低可信 |
|---------|-------|-------|-------|
| 主体 | 官方/权威机构 | 主流媒体 | 自媒体/个人 |
| 证据 | 原始文件/数据 | 引用数据 | 无数据支撑 |
| 透明度 | 公开可查 | 部分可查 | 不透明 |

### 步骤三：交叉验证

1. **提取关键信息**：从每个来源提取核心事实
2. **比对一致性**：
   - ✅ 完全一致 → 可采信
   - ⚠️ 部分差异 → 标注差异点，追溯原因
   - ❌ 明显矛盾 → 不可采信，需进一步验证
3. **确认独立性**：确保不是同一来源的多次引用

### 步骤四：标注输出

```
【事实】[已验证事实]（来源：A、B、C）
【推断】[推断内容]（依据：X事实+Y事实）
【预测】[预测内容]（依据：趋势分析）
【待验证】[未验证信息]（来源：单源）
```

## ⚠️ 异常处理

### 来源不足怎么办？

| 情况 | 处理 |
|------|------|
| 只有1个来源 | 标注【待验证】，说明原因 |
| 只有2个来源 | 标注【待验证】，说明需要第3源 |
| 来源有利益冲突 | 降低权重，寻找独立来源 |
| 无法找到更多来源 | 如实说明，不建议采信 |

### 来源矛盾怎么办？

| 情况 | 处理 |
|------|------|
| 官方vs非官方 | 以官方为准，标注差异 |
| 同级别来源矛盾 | 标注矛盾，不采信，待澄清 |
| 新信息vs旧信息 | 以最新为准，标注更新时间 |
