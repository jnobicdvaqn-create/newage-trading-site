## 二、研讨决议 `#decision #质控`

### R-QC-001：质控前置检查流程（强制执行）

**决议内容：**
```
每日汇报前强制过质控清单：
1. 来源：≥3源？权重标注？
2. 标注：推断【推断】？单源【待验证】？
3. 逻辑：因果完整？无跳跃？
```

**核查标准：**
- 每份报告末尾增加"质控检查签名"
- 格式：`质控检查：✅三源验证 ✅标注完整 ✅逻辑清晰 - [审核人]`

**执行人：** 全员
**监督人：** 助理二号

---

### R-QC-002：违规熔断机制（强制执行）

**决议内容：**
```
违规触发条件：
- 关键推断无依据 → 立即标注补依据
- 单源信息未标注 → 立即标注"待验证"
- 数据编造 → 报告废弃重写
```

**核查标准：**
- 助理二号每日抽查1份报告
- 发现违规→飞书告警→当日整改

**执行人：** 助理二号
**监督人：** 星期六
