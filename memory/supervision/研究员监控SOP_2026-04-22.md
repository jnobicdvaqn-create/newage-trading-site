## 📊 监控规则

### 落后分级标准

| 落后天数 | 告警级别 | 行动 | 通知渠道 |
|---------|---------|------|---------|
| **落后1天** | 🟡 黄色提醒 | 记录 + 研讨提醒 | TODO.md标注 + 研讨口头提醒 |
| **落后3天** | 🟠 橙色告警 | 飞书告警主人 + 任务重新分配 | 飞书私信主人 + 研讨重新分配议案 |
| **落后7天** | 🔴 红色告警 | 专项整改研讨 | 飞书告警 + 民主生活会专项议题 |

### 落后计算标准

- **截止时间定义：** TODO.md中的截止日期+时间
- **落后计算：** 当前时间 - 截止时间 > 24小时 = 落后1天
- **豁免条件：**
  - BLOCKED状态任务（等待主人/外部反馈）
  - 主人明确延期批准的任务

## 🚨 告警执行流程

### 黄色提醒（落后1天）

1. 助理二号在研讨中口头提醒负责人
2. 星期五三世更新TODO.md标注"落后1天"
3. 记录到 `memory/supervision/落后检查_YYYY-MM-DD.md`

### 橙色告警（落后3天）

1. 助理二号飞书私信主人
   - 格式：`【落后告警 - 橙色】任务：XXX，负责人：XXX，落后3天，建议重新分配`
2. 星期五三世在研讨提出重新分配议案
3. 更新TODO.md标注"落后3天 - 告警主人"
4. 记录详细告警内容到supervision文件

### 红色告警（落后7天）

1. 助理二号飞书告警主人
2. 星期五三世启动民主生活会专项整改议题
3. 重新分配任务，制定整改方案
4. 记录整改决议到memory/

## 📝 成员状态监控

### 状态定义

| 状态 | 定义 | 监控重点 |
|------|------|---------|
| **ACTIVE** | 正常执行任务 | 检查产出质量 |
| **BLOCKED** | 阻塞中（等待外部） | 监控阻塞时长 |
| **IDLE** | 无分配任务 | 分配新任务或学习研讨 |
| **OFFLINE** | 长时间无响应 | 橙色告警 |

## 📌 特殊情况处理

### 阻塞任务处理

- 阻塞>24h → 启动Plan B（参考HEARTBEAT.md）
- 阻塞>48h → 飞书告警主人

### 豁免任务标注

- 在TODO.md中标注 `[豁免] 原因：等待主人确认`
- 不计入落后统计

### 主人临时调整

- 主人明确调整截止时间 → 更新TODO.md
- 不追溯之前落后天数

## 🎯 监督闭环

```
任务分配 → 执行 → 监控 → 发现落后 → 告警 → 处理 → 验证 → 记录
```

**每次监控必须形成闭环：**
- 发现问题 → 必须告警
- 告警 → 必须处理
- 处理 → 必须验证
- 验证 → 必须记录
