## 📋 巡检清单

### 一、任务系统巡检

| 检查项 | 检查方法 | 正常标准 | 异常处理 |
|--------|---------|---------|---------|
| **TODO.md状态** | 读取TODO.md | 无逾期任务 | 标记逾期，启动升级机制 |
| **P0任务进度** | 检查P0状态 | 全部进行中/完成 | 黄色告警，督促执行 |
| **阻塞任务** | 检查BLOCKED状态 | 无或<24h | >24h启动Plan B |
| **已批准未启动** | 检查启动时间 | 全部已启动 | 立即启动，记录违规 |
| **决议执行率** | 检查决议完成状态 | ≥80% | 分析原因，重新分配 |

**执行命令：**
```bash
# 检查逾期任务
grep -n "⏳" ~/openclaw/workspace/TODO.md

# 检查阻塞任务
grep -n "❌" ~/openclaw/workspace/TODO.md

# 检查P0任务
grep -n "P0" ~/openclaw/workspace/TODO.md
```

### 二、系统运行巡检

| 检查项 | 检查方法 | 正常标准 | 异常处理 |
|--------|---------|---------|---------|
| **ClawSwarm运行** | `curl localhost:18080` | 返回200 | 自动重启，飞书告警 |
| **OpenClaw Gateway** | `openclaw gateway status` | 运行中 | 重启服务 |
| **Cron任务** | `crontab -l` | 任务正常 | 修复任务 |
| **磁盘空间** | `df -h` | >20%可用 | 清理文件 |
| **内存使用** | `free -h` | <80% | 重启服务 |

**执行命令：**
```bash
# 检查ClawSwarm
curl -s -o /dev/null -w "%{http_code}" localhost:18080

# 检查OpenClaw Gateway
openclaw gateway status

# 检查磁盘空间
df -h | grep -E '(Filesystem|/$)'

# 检查内存
free -h
```
